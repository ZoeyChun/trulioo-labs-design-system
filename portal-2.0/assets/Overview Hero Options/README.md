# Overview hero — left-side options

Decision gallery for the KYB Overview hero **left column** (gauge / risk verdict area).
The right-side entity facts card stays identical across every option.

| | URL |
|--|--|
| Local | `portal-2.0/assets/Overview Hero Options/index.html` |
| GitHub Pages | `…/portal-2.0/assets/Overview%20Hero%20Options/` |

## Controls

- **Risk filter** — High / Medium / Low Risk (shared across all options)
- **Business Risk Horizon** — one shared BRH toggle for every option

## Options

| Id | Name | How findings appear | CTAs |
|--|--|--|--|
| `side` | Classic side header | Vertical marked bullets | Secondary row |
| `stack` | Score billboard | Ranked rows + impact bars | Full-width stack |
| `mosaic` | KPI mosaic | Inside the tiles (no list) | Text links |
| `banner` | Alert strip | Horizontal wrap chips | Inline under strip |
| `rail` | Split panel | Numbered narrative list | Full-width stack |
