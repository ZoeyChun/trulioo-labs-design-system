# Demo 3 — Home 6

White hero with the flat dot field from [`../hero-options/`](../hero-options/) ("White" option):
60px grid, teal circles, cascade, link mesh and hover glow. A soft mint glow
sits at the sides and fades out before the hero's edge, so the hero blends
into the cards below with no divider.
