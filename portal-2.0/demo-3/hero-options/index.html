Three final dot fields

Demo 3 main Dot playground

One dot field, three surfaces. Same 60px grid, same teal 1.6px dots at 45%, same cascade at 0.08/s, same clear hole, same mesh at 0.10, same spotlight on hover. The background is the only thing that differs. Hover a hero for the pointer response; hide the copy to judge the field on its own.

All three need js/tru-dot-lab.js — the shipped TruDotField has no cascade, no link mesh and no pointer response. To ship one, point the home at that engine instead of dot-field.js (the mount signature is identical), or port those three features across.
