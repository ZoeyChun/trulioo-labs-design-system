# Demo 3 — Home dot lab

Tune the dark-green hero TruDotField with a demo-2-style configuration panel. Dots are clipped inside the hero only (no card section).

|--|--|

## Merge back into Demo 3 main

1. Open the lab, tweak until it looks right.
2. **Copy config** (clipboard includes `DARK_CONFIG`).
3. Paste into `portal-2.0/demo-3/js/d3-home-dots.js` → replace `DARK_CONFIG`.
4. Reload Demo 3 main home to verify.

Settings use localStorage key `d3-home-dot-lab-v1` (separate from demo-2).
