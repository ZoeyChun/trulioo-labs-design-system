# UBO Graph

KYB investigation relationship network — interactive entity graph with ownership, director, address, and risk edges.

## Live demo (GitHub Pages)

**https://zoeychun.github.io/trulioo-labs-design-system/pages/Experiments/ubo-graph/site/**

Shortcut: [live.html](./live.html) redirects to the demo.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Build for GitHub Pages

```bash
npm run build
```

Output is written to `site/`. Pushes to `main` that touch this folder trigger `.github/workflows/deploy-ubo-graph.yml`, which rebuilds and commits `site/` automatically.
